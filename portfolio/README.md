# 📊 포트폴리오 수익률 대시보드

거래내역 CSV와 주식잔고 CSV를 넣으면 **현재 잔고 · 거래내역 · 매매일지 · 포트폴리오 변화 추이**를
한 화면에서 보는 도구입니다.

구성:
- `portfolio_dashboard.html` — 브라우저에서 보는 대시보드 (모든 계산/저장이 브라우저 안에서 일어남)
- `fetch_prices.py` — 네이버에서 현재가/지수/환율을 받아 `prices.json` 으로 저장 (시세 새로고침용)

---

## 처음 한 번: 준비

1. **파이썬 설치 확인** (3.8 이상)
   ```bash
   python --version
   ```
2. **필요한 패키지 설치**
   ```bash
   pip install -r requirements.txt
   ```

---

## 실행 방법 (매번)

> ⚠️ **그냥 HTML을 더블클릭하면 안 됩니다.** 브라우저 보안 때문에 `prices.json`을 못 읽어요.
> 반드시 아래처럼 작은 웹서버로 띄워야 시세 새로고침이 됩니다.

### 한 번에 실행 (추천)

- **Mac / Linux**: 터미널에서 `portfolio` 폴더로 이동 후
  ```bash
  ./start_dashboard.sh
  ```
- **Windows**: `start_dashboard.bat` 더블클릭

### 직접 실행 (수동)

`portfolio` 폴더 안에서:

```bash
# 1) 현재가/지수/환율 받아오기 → prices.json 생성
python fetch_prices.py

# 2) 로컬 웹서버 띄우기
python -m http.server 8000
```

그리고 브라우저에서 열기: **http://localhost:8000/portfolio_dashboard.html**

## 화면에서 하는 일

1. **CSV 가져오기** 버튼 → 증권사에서 받은 **주식잔고 CSV** 선택 → 보유 종목이 채워짐
2. **거래내역 CSV 가져오기** 버튼 → **거래내역 CSV** 선택 → 매매일지/실현손익이 쌓임
3. **↻ 시세 새로고침** 버튼 → `fetch_prices.py`가 만든 `prices.json`을 읽어 현재가·지수 갱신
   - 누를 때마다 그날 총자산이 기록돼서 **포트폴리오 변화 추이** 곡선이 쌓입니다
4. 입력한 데이터는 브라우저(localStorage)에 저장됩니다. **백업저장** 버튼으로 JSON 백업도 가능

### 구글 시트를 원본으로 쓰기 ⭐ (URL 하나면 모든 탭=계좌 자동)

증권사 거래내역 CSV가 기간별로 잘려 나와도, **시트 한 곳에 계속 이어붙이면** 전체 내역이
누적돼요. **계좌는 시트 안의 탭**으로 두고(예: `계좌01`, `계좌02`), 대시보드는 **웹앱 URL 하나로**
모든 탭을 알아서 긁어옵니다. 계좌가 늘면 **탭만 추가**하면 끝 — 설정 변경 불필요.

**준비 (한 번만)**
1. 구글 시트를 만들고, 아래쪽 **탭을 계좌별로** 만들기 → 예: `계좌01`, `계좌02` (탭 이름이 곧 계좌 이름)
2. 각 계좌 거래내역 CSV를 **그 탭에 통째로 복붙**. (기간별로 새로 받을 때마다 이어붙이면 됨 — 헤더가 중복돼도 알아서 걸러요)
3. **확장 프로그램 → Apps Script**에 이 폴더의 **`google_apps_script.gs`** 코드 붙여넣고 저장
4. **배포 → 새 배포 → 웹 앱** / 실행 주체 **나**, 액세스 **모든 사용자** → 나온 URL(`…/exec`) 복사
   (`google_apps_script.gs`를 고친 뒤엔 **배포 → 배포 관리 → 편집 → 버전: 새 버전**으로 다시 배포)

**대시보드에서 (URL 하나만)**
1. 상단 **`시트연결`** → 위 URL 붙여넣기 (한 번만)
2. **`⟳ 시트에서 불러오기`** → 모든 탭을 읽어 **보유종목·평단가·매매일지·입출금**을 자동 계산 (누를 때마다 시트 최신으로)
3. **`↻ 시세 새로고침`** → 현재가 채우기

> 같은 URL이 **읽기(시트에서 불러오기)** 와 **쓰기(📗 구글시트 백업)** 를 모두 처리해요.
> 시세(`fetch_prices.py`)는 여전히 따로 돌려야 해요(시트엔 시세가 없으니까).
> ⚠️ 이 웹앱 URL을 아는 사람은 시트를 읽고 쓸 수 있어요. **비공개로** 두세요.

### 거래내역만으로 현재 보유 종목 만들기 (잔고 CSV 없어도 됨)
증권사 **거래내역 CSV**만 있으면 현재 계좌를 통째로 재구성할 수 있어요.
1. `거래내역 CSV 가져오기`(또는 `CSV 가져오기`)로 거래내역 파일을 가져오기 — 파일이 거래내역이면 **자동으로 인식**해서 처리합니다. 파일명에서 계좌번호(…401 → `계좌01`)를 따와 계좌 이름을 제안해줘요.
2. 보유 종목 카드의 **`거래내역으로 보유 계산`** 버튼 클릭 → 매수−매도를 합쳐 **현재 수량·평단가**를 계산 (다 팔린 종목은 자동 제외)
3. `↻ 시세 새로고침` → 현재가가 채워짐

### 계좌가 여러 개일 때 (예: 계좌01, 계좌02)
- **각 계좌 파일을 하나씩** 가져오면 됩니다. (다시 가져와도 기존 게 안 지워지고 계좌별로 쌓여요)
- 화면 위쪽 **`계좌` 선택 버튼**으로 `전체(합산)` ↔ `계좌01` ↔ `계좌02`를 전환하며 볼 수 있어요.
- 추이/벤치마크 곡선은 항상 **전체 합산 기준**으로 기록됩니다.

### 정리 / 삭제
- **특정 계좌 삭제**: 그 계좌를 선택한 뒤 계좌 줄의 **`✕ 계좌 삭제`** 버튼 → 그 계좌의 보유종목·거래내역만 지워져요.
- **전체 초기화**: 상단의 **`초기화`** 버튼 → 보유종목·거래내역·매매일지를 모두 비웁니다. (현금/환율/추이 기록은 유지. 필요하면 먼저 `백업저장`)

### CSV 형식 메모
- `fetch_prices.py`는 폴더 안의 CSV 중 **`잔고수량`(또는 `수량`+`매입단가`) 열이 있는 파일**을
  자동으로 골라 종목 코드를 읽습니다. 잔고 CSV를 이 폴더에 두세요.
- 잔고/거래내역 CSV는 한글 인코딩(EUC-KR/CP949)이어도 대시보드가 알아서 읽습니다.
- 양식이 궁금하면 대시보드의 **양식** 버튼으로 샘플 CSV를 받아볼 수 있어요.

## 구글 시트 연동 (백업)

대시보드 데이터(보유종목·거래내역·자산추이·입출금·월별요약)를 내 구글 시트에 백업할 수 있어요.
정적 페이지에서 시트에 직접 쓰려면 **구글 쪽에 한 번만** 작은 "Apps Script 웹앱"을 만들어 붙입니다.

**한 번만 설정 (약 5분)**
1. 구글 시트를 새로 만들기 ([sheets.new](https://sheets.new))
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 편집기에 있는 코드를 지우고, 이 폴더의 **`google_apps_script.gs`** 내용을 통째로 붙여넣고 💾 저장
4. 오른쪽 위 **배포(Deploy) → 새 배포 → 유형: 웹 앱**
   - 실행 주체(Execute as): **나(Me)**
   - 액세스 권한(Who has access): **모든 사용자(Anyone)** ← 대시보드가 익명으로 보내기 때문
5. 처음이면 권한 승인(내 계정 선택 → "고급" → 허용)
6. 만들어진 **웹 앱 URL**(`…/exec`로 끝남)을 복사

**대시보드에서**
1. 상단 **`시트연결`** 버튼 → 복사한 URL 붙여넣기 (한 번만)
2. 이후 **`📗 구글시트 백업`** 버튼을 누를 때마다 → 시트에 다음 탭이 채워져요:
   `보유종목` · `거래내역` · `자산추이` · `입출금` · `월별요약` · `정보`
3. 스크린샷 같은 **평가액/입출금/수익금/수익률** 표는 `월별요약` 탭에 자동 생성돼요.
   (목표금액 칸이나 차트는 시트에서 원하는 대로 더 꾸미면 됩니다)

> ⚠️ 이 웹앱 URL을 아는 사람은 시트에 쓸 수 있어요(읽기는 불가). **URL은 비공개로** 두세요.
> 월별요약의 평가액/수익률은 **'시세 새로고침'으로 쌓인 자산추이 기록**을 기준으로 해서, 기록이 쌓일수록 채워집니다. 입출금은 거래내역 전체에서 잡혀요.

## 환율 자동 갱신 (선택)

`fetch_prices.py` 안의 `EXIM_KEY = ""` 에 수출입은행 인증키를 넣으면 USD/TWD 환율도 자동 갱신됩니다.
비워두면 환율은 대시보드에서 직접 입력한 값을 씁니다.
