# 📊 포트폴리오 수익률 대시보드

거래내역 CSV와 주식잔고 CSV를 넣으면 **현재 잔고 · 거래내역 · 매매일지 · 포트폴리오 변화 추이**를
한 화면에서 보는 도구입니다.

구성:
- `portfolio_dashboard.html` — 브라우저에서 보는 대시보드 (모든 계산/저장이 브라우저 안에서 일어남)
- `fetch_prices.py` — 네이버에서 현재가/지수/환율을 받아 `prices.json` 으로 저장 (시세 새로고침용)

---

## 처음 한 번: 준비

1. **파이썬 설치 확인** (3.8 이상)
   ```bash
   python --version
   ```
2. **필요한 패키지 설치**
   ```bash
   pip install -r requirements.txt
   ```

---

## 실행 방법 (매번)

> ⚠️ **그냥 HTML을 더블클릭하면 안 됩니다.** 브라우저 보안 때문에 `prices.json`을 못 읽어요.
> 반드시 아래처럼 작은 웹서버로 띄워야 시세 새로고침이 됩니다.

### 한 번에 실행 (추천)

- **Mac / Linux**: 터미널에서 `portfolio` 폴더로 이동 후
  ```bash
  ./start_dashboard.sh
  ```
- **Windows**: `start_dashboard.bat` 더블클릭

### 직접 실행 (수동)

`portfolio` 폴더 안에서:

```bash
# 1) 현재가/지수/환율 받아오기 → prices.json 생성
python fetch_prices.py

# 2) 로컬 웹서버 띄우기
python -m http.server 8000
```

그리고 브라우저에서 열기: **http://localhost:8000/portfolio_dashboard.html**

---

## 화면에서 하는 일

1. **CSV 가져오기** 버튼 → 증권사에서 받은 **주식잔고 CSV** 선택 → 보유 종목이 채워짐
2. **거래내역 CSV 가져오기** 버튼 → **거래내역 CSV** 선택 → 매매일지/실현손익이 쌓임
3. **↻ 시세 새로고침** 버튼 → `fetch_prices.py`가 만든 `prices.json`을 읽어 현재가·지수 갱신
   - 누를 때마다 그날 총자산이 기록돼서 **포트폴리오 변화 추이** 곡선이 쌓입니다
4. 입력한 데이터는 브라우저(localStorage)에 저장됩니다. **백업저장** 버튼으로 JSON 백업도 가능

### CSV 형식 메모
- `fetch_prices.py`는 폴더 안의 CSV 중 **`잔고수량`(또는 `수량`+`매입단가`) 열이 있는 파일**을
  자동으로 골라 종목 코드를 읽습니다. 잔고 CSV를 이 폴더에 두세요.
- 잔고/거래내역 CSV는 한글 인코딩(EUC-KR/CP949)이어도 대시보드가 알아서 읽습니다.
- 양식이 궁금하면 대시보드의 **양식** 버튼으로 샘플 CSV를 받아볼 수 있어요.

---

## 환율 자동 갱신 (선택)

`fetch_prices.py` 안의 `EXIM_KEY = ""` 에 수출입은행 인증키를 넣으면 USD/TWD 환율도 자동 갱신됩니다.
비워두면 환율은 대시보드에서 직접 입력한 값을 씁니다.

## 한계 / 참고
- 현재가 자동 갱신은 **국내 종목**만 됩니다(네이버 국내 시세). 해외 종목은 직접 입력하세요.
- 추이/벤치마크 곡선은 **시세 새로고침할 때마다 기록이 쌓이는** 구조라, 처음엔 데이터가 적습니다.
- 투자 판단 보조용이며 매수 추천이 아닙니다.
