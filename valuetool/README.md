# 📊 밸류툴 자동 업데이트 (Google Sheets + DART)

`valuetool20250808.xlsb` 가치평가 시트의 **수동 입력을 자동화**하는 도구.

- **현재가** → `=GOOGLEFINANCE("KRX:<코드>")` (약 20분 지연, 자동 갱신)
- **펀더멘털**(매출·영업이익·분기순익·자본총계) → **Open DART API**

> 한국 종목 펀더멘털의 정답은 **DART(금감원 전자공시)** 입니다.
> Yahoo/Google 은 한국 펀더멘털 커버리지가 부실하고, 네이버는 스크래핑이라
> 깨지기 쉬워 차선입니다. DART 는 공식·무료(이메일 가입 → 인증키)입니다.

## 설계 원칙 — 기존 모델을 안 건드린다

`.xlsb` 는 수식층이 숨겨져 있어 내부 계산식을 그대로 재현하긴 어렵습니다.
그래서 지금 쓰시는 방식(시트 `1`에 가격 붙여넣고 `VLOOKUP`)을 그대로 살립니다.

```
툴이 만드는 참조 테이블          기존 모델
┌──────────────┐
│ _price 시트   │  ← GOOGLEFINANCE   ┐
│ stock_code    │                    ├─ VLOOKUP(코드, _price, …)
│ name / 현재가  │                    ┘
└──────────────┘
┌──────────────┐
│ _dart 시트    │  ← DART API        ┐
│ 매출/영업이익  │                    ├─ VLOOKUP(코드, _dart, …)
│ 분기순익/자본  │                    ┘
└──────────────┘
```

기존 시트의 가격·순익·자본총계 입력칸 수식만 위 두 시트를 `VLOOKUP` 하도록
바꾸면 끝입니다.

## 갱신 주기

| 데이터 | 소스 | 주기 | 방법 |
|--------|------|------|------|
| 현재가 | GOOGLEFINANCE | 자동(상시) | 한 번 설정하면 끝 |
| 펀더멘털 | DART | 분기 1회 | 메뉴 버튼 클릭 |

## 설치

### 1. xlsb → Google Sheets 이전
1. `.xlsb` 를 Excel 에서 열어 **`.xlsx` 로 저장** (구글시트는 xlsb 직접 import 불가)
2. Google Drive 에 업로드 → **Google Sheets 로 열기**(자동 변환)

### 2. 종목 목록 import
- 이 폴더의 **`codes_seed.csv`** (2,423종목, `stock_code`/`name`/sector) 를
  `_codes` 라는 새 시트로 import. (A열=코드, B열=종목명, 1행 헤더)

### 3. DART 인증키 발급
- <https://opendart.fss.or.kr> → **인증키 신청/관리** → 이메일 가입 → 키 발급(무료)
- 일일 호출 한도 **20,000건/키** (사이트 공지 기준) — 이 툴은 분기 1회 수백 건 수준

### 4. Apps Script 붙여넣기
1. 시트 상단 **확장 프로그램 → Apps Script**
2. `Code.gs` 내용 전체 붙여넣기
3. 상단 `CONFIG.DART_KEY` 에 발급받은 키 입력, `CONFIG.BSNS_YEAR` 확인
4. 저장 후 시트로 돌아와 새로고침 → 상단에 **📊 밸류툴** 메뉴 생성

### 5. 실행 순서
1. **① 가격 시트 만들기** → `_price` 생성, GOOGLEFINANCE 자동 가동
2. **② corp_code 매핑** (최초 1회) → DART 는 6자리 종목코드가 아니라
   8자리 `corp_code` 를 쓰므로 `corpCode.xml` 로 매핑 캐시 생성
3. **③ DART 펀더멘털 갱신** (분기마다) → `_dart` 채움
   - 6분 실행제한이 있어 자동으로 청크 처리 + 1분 뒤 이어서 실행됩니다
   - 처음엔 권한 승인 팝업이 뜹니다(본인 계정, 정상)

## 분기순익 분리 로직

DART 손익 항목(`thstrm_amount`)은 **누적**으로 옵니다. 단일 분기로 분리:

```
1Q = 1분기보고서(11013)
2Q = 반기보고서(11012)   − 1Q
3Q = 3분기보고서(11014)  − 반기
4Q = 사업보고서(11011)   − 3분기누적
```

자본총계 등 재무상태표 항목은 시점값이라 가장 최근 보고서 값을 사용합니다.
(단위는 **억원**으로 변환되어 기록됩니다.)

## 알려진 한계

- **금융사(은행·보험·증권)**: DART `주요계정` API 는 금융업을 제외합니다.
  KB금융 등은 `_dart` 에 값이 비어 자본총계/순익이 누락될 수 있습니다.
  → 해당 종목은 전체재무제표(`fnlttSinglAcntAll`) 별도 처리 또는 수동 보완 필요.
- **GOOGLEFINANCE**: 약 20분 지연가이며 일부 종목/우선주는 `#N/A` 가능.
  대량(2,400+) 호출 시 일시적 `#N/A` 가 날 수 있어 재계산이 필요할 수 있습니다.
- `CONFIG.DART_CHUNK` 응답이 비면 50→20 으로 줄이세요(다중회사 묶음 수 제한 대응).
