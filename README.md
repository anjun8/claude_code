# 📈 KOSPI/KOSDAQ 급등 거래대금 스크리너

정규장 마감 후 **거래대금이 크게 터진 급등 종목**을 자동으로 필터링해서
섹터 동반 강세·뉴스·3개월 추세까지 묶어 **텔레그램으로 전달**하는 시스템.

> "보고 싶은 것만 보는" 습관을 의지가 아니라 *구조화된 시스템*으로 극복하기 위한 도구.
> 매수 여부와 무관하게, 그날 시장에서 **왜 강했는지** / **어떤 섹터에 액션이 났는지**를
> 매일 빠짐없이 점검하는 것이 목적이다.

## 필터 조건 (기본값)

| 조건 | 기본값 | 환경변수 |
|------|--------|----------|
| 거래대금 | **2천억 원 이상** | `SCREEN_VALUE_EOK` |
| 등락률 | **+10% 이상** | `SCREEN_CHANGE_PCT` |
| 시가총액 | **30조 원 이하** | `SCREEN_MARKETCAP_JO` |

통과 종목마다 다음을 함께 계산한다.

- **3개월 수익률** & **3개월 거래대금 2천억↑ 횟수** (추세 강도)
- **동일 섹터 동반 상승** 종목 (섹터 액션 감지)
- **뉴스 헤드라인** (선택, 네이버 검색 API)

그리고 마지막에 **오늘의 주목 포인트**를 자동 요약한다.

- 한 섹터에서 통과 종목이 2개 이상 → "**테마 집중**"
- 섹터 전반 동반 상승 → "**섹터 전반 강세**"
- **상한가** 종목
- 3개월 +100% 이상인 **단기 급등 지속(추격 주의)** 종목

## 빠른 시작

```bash
pip install -r requirements.txt

# 0) 자격증명 없이 동작 확인 (합성 데이터, 네트워크 X) ← 설치 직후 스모크 테스트
python -m screener.cli --demo --dry-run

# 1) 단위 테스트
python -m pytest -q

# 2) 자격증명 세팅 후 실데이터로 콘솔 출력만 (전송 X)
cp .env.example .env        # KRX_ID/PW 등 값 채우기
python -m screener.cli --dry-run

# 3) 특정일 + 텔레그램 전송
python -m screener.cli --date 2026-04-08
```

### 옵션

| 플래그 | 설명 |
|--------|------|
| `--demo` | 네트워크/자격증명 없이 합성 데이터로 실행 (스모크 테스트) |
| `--date YYYY-MM-DD` | 대상일 지정 (기본: 직전 영업일) |
| `--dry-run` | 전송하지 않고 콘솔 출력 |
| `--no-trend` | 3개월 추세 계산 생략 (빠름) |
| `--no-news` | 뉴스 헤드라인 생략 |

## 환경변수 / 키 발급

| 변수 | 용도 | 발급처 |
|------|------|--------|
| `KRX_ID`, `KRX_PW` | **pykrx 1.2.x 데이터 조회에 필수** | [data.krx.co.kr](http://data.krx.co.kr) 회원가입 |
| `TELEGRAM_BOT_TOKEN` | 봇 토큰 | 텔레그램 [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | 수신 채팅 ID | 봇과 대화 후 `getUpdates`로 확인 |
| `NAVER_CLIENT_ID/SECRET` | 뉴스 헤드라인(선택) | [네이버 개발자센터](https://developers.naver.com) |

> ⚠️ `TELEGRAM_*`가 없으면 전송 대신 콘솔에 출력한다.
> `NAVER_*`가 없으면 📰 줄을 생략한다. 둘 다 없어도 핵심 스크리닝은 동작한다.

## 자동 스케줄 (GitHub Actions)

`.github/workflows/screener.yml`가 **평일 16:10 KST**(장 마감 후)에 자동 실행된다.
저장소 **Settings → Secrets and variables → Actions**에 위 환경변수들을
시크릿으로 등록하면 끝. `workflow_dispatch`로 수동/특정일 실행도 가능하다.

서버에서 직접 cron으로 돌리려면:

```cron
10 16 * * 1-5  cd /path/to/repo && /usr/bin/python3 -m screener.cli >> screener.log 2>&1
```

## 구조

```
screener/
  config.py       # 임계값/시크릿 (환경변수 로드)
  datasource.py   # pykrx 실데이터 수집 (유일한 네트워크 계층)
  screen.py       # 필터·동반상승·주목포인트 (순수 함수, 테스트 가능)
  formatter.py    # 텔레그램 메시지 포맷
  news.py         # 뉴스 헤드라인 (선택, best-effort)
  notify.py       # 텔레그램 전송
  cli.py          # 오케스트레이션 엔트리포인트
tests/            # 합성 데이터 기반 단위 테스트 (네트워크 불필요)
```

## 참고 / 한계

- **섹터**는 KRX 업종명을 사용한다. 예시의 GICS식 세분류(예: "반도체와반도체장비")와
  명칭이 다를 수 있다(예: "전기전자").
- pykrx는 KRX 서버에 의존하므로 장중/지연/점검 시 실패할 수 있다. 실패 시 종목은
  3개월/뉴스 정보 없이도 핵심 정보로 출력된다.
- 본 도구는 **투자 판단 보조용**이며 매수 추천이 아니다.
