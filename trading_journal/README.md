# 📓 주식 매매일지 (거래장부 + 성과 대시보드)

증권사 거래내역을 바탕으로 매매 1건씩을 기록하고, **매수/매도 시점·평균 수익·평균 손실·
수익 거래 비율(승률)·평균 보유기간·월별 최대 수익/손실**을 자동으로 집계하는 엑셀 워크북.

- 산출물: `주식_매매일지.xlsx`
- 생성기: `build_journal.py` (워크북 전체를 코드로 재생성한다)

전략(가치투자·스윙트레이딩·데이트레이딩)마다 장부를 따로 관리하는 구조이며,
현재는 **스윙트레이딩 1개 전략**으로 만들어져 있다.

## 시트 구성

| 시트 | 역할 |
|------|------|
| `사용법` | 입력 규칙, 색 규칙, 지표 정의 |
| `설정` | 계좌명·초기자본·수수료율·대시보드 시작월 등 공통 파라미터 |
| `거래장부_스윙트레이딩` | **실제로 입력하는 곳.** 매매 1건(매수~매도 한 사이클)이 1행 |
| `대시보드_스윙트레이딩` | 해당 전략의 성과 요약. 전부 수식 |
| `원본거래내역` | 증권사 HTS/MTS 거래내역 원본 붙여넣기용 보관 시트 |

## 입력 방법

노란 칸(파란 글씨)만 채우면 되고, 회색 칸은 수식이므로 건드리지 않는다.

1. **매수 체결 직후** — 종목코드, 종목명, 매수일자, 매수단가, 수량, 매수수수료, 매매유형, 메모
   → 상태가 `보유중`이 되고 손익 집계에서 빠진다.
2. **매도 체결 후** — 매도일자, 매도단가, 매도수수료, 제세금
   → 상태가 `청산`으로 바뀌며 순손익·수익률·보유일수·청산월이 계산된다.

주황색으로 칠해진 예시 3행(6~8행)은 실제 사용 전에 삭제한다.

## 대시보드가 보여주는 것

- **종합 성과** — 청산/보유중 건수, 승률, 총 실현손익, 손익비(Profit Factor), 기대값, 총 거래비용
- **평균 지표** — 평균 수익/손실, 평균 손익비(R/R), 구간별 평균 수익률, 평균 보유일수, 최대 연속 수익/손실
- **최고/최악** — 최대 수익·손실 거래와 그 종목, 최고/최저 수익률, 최장 보유일수, 초기자본 대비 수익률
- **월별 성과** — 24개월치 청산 건수·실현손익·누적 손익·승률·최대 수익·최대 손실 (+ 막대/선 차트)
- **수익 TOP 5 / 손실 TOP 5**
- **종목별 요약** — 종목명을 직접 입력하면 그 종목만 집계
- **매매유형별 요약** — 돌파/눌림목/추세추종 등 태그별 성과

## 전략 추가하기

`build_journal.py` 의 `STRATEGIES` 에 전략명을 추가하고 다시 실행하면
`거래장부_<전략>` + `대시보드_<전략>` 시트 쌍이 그대로 늘어난다.

```python
STRATEGIES = ["가치투자", "스윙트레이딩", "데이트레이딩"]
```

```bash
python trading_journal/build_journal.py
```

> ⚠️ 재생성하면 파일을 새로 덮어쓰므로 **기존에 입력한 거래 데이터가 사라진다.**
> 이미 기록을 쌓았다면 엑셀에서 시트를 우클릭 → 이동/복사 → 복사본 만들기로 늘리고,
> 새 대시보드 수식의 시트 이름만 새 장부 이름으로 일괄 치환하는 편이 안전하다.

## 계산 규칙

| 항목 | 정의 |
|------|------|
| 순손익 | 총매도금액 − 총매수금액 − (매수수수료 + 매도수수료 + 제세금) |
| 수익률 | 순손익 ÷ 총매수금액 (연환산하지 않은 실현 수익률) |
| 승률 | 수익 거래 수 ÷ 청산 거래 수 (보유중 거래 제외) |
| 손익비 | 총수익 합계 ÷ \|총손실 합계\| |
| 기대값 | 총 실현손익 ÷ 청산 거래 수 |
| 보유일수 | 청산 = 매도일자 − 매수일자 / 보유중 = 오늘 − 매수일자 |

수수료율·거래세율은 `설정` 시트의 **참고용 상수**이며 손익 계산에 직접 쓰이지 않는다.
장부에는 증권사가 실제로 부과한 금액을 원 단위로 입력할 것.

## 알려진 제약

- 월별·종목별·유형별 요약과 승률은 모두 **청산 거래 기준**이다. 보유중 거래는 평가손익을
  계산하지 않으므로(현재가 입력란이 없음) 집계에 포함되지 않는다.
- TOP 5 표는 순손익이 완전히 동일한 거래가 둘 이상이면 첫 번째 거래만 반복 표시된다.
- 최대 연속 수익/손실은 장부의 **행 순서** 기준이므로 매수일자 오름차순 정렬을 유지해야 한다.
- 분할매수/분할매도는 평균단가와 총수량으로 합쳐 한 행에 적거나, 매수 묶음별로 행을 나눈다.
  둘 중 하나로 일관되게 기록해야 보유일수 통계가 왜곡되지 않는다.
